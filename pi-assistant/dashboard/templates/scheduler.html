How to Add a Scheduled Job

Schedule jobs from within a plugin's setup() method using the assistant's scheduler: 

# Every 30 minutes
self.assistant.scheduler.add_interval_job(
    func=self.my_task, job_id="my_plugin.my_task", minutes=30
)

# Every weekday at 08:00
self.assistant.scheduler.add_cron_job(
    func=self.morning_brief, job_id="my_plugin.brief",
    day_of_week="mon-fri", hour=8, minute=0
)
